# Assignment-2-K-Means-DBSCAN-Clustering
This repository covers my experience using K-Means and DBSCAN clustering techniques on the Olivetti Faces dataset

## Simple Dodge-the-Blocks Game

A tiny terminal game is available in `simple_game.py`:

```bash
python simple_game.py --rows 6 --cols 6 --seed 42 --max-turns 10
```

* Move with `W`, `A`, `S`, `D` (or press Enter to stay). Avoid the falling `X` blocks.
* Use `--moves a,d,w` to script inputs for quick testing.
